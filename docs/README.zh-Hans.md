# Home Assistant 的 FERMAX LYNX 网关集成

通过局域网直接连接网关，无需 MQTT、云账号或额外 HA OS 应用。要求 Home Assistant 2026.9+、网关 0.7.0+（API schema 1）。本项目是自定义集成，**尚未收录 HACS 默认商店**。

## 安装与配对

1. HACS → 右上角菜单 → 自定义仓库，添加 `https://github.com/helixzz/ha-fermax-lynx`，类别为 Integration；下载后重启 HA。也可以手动将仓库中的 `custom_components/fermax_lynx` 复制到 `/config/custom_components/fermax_lynx` 后重启。
2. 在网关管理员界面生成短时、一次性集成配对码，选择入口与权限。读取状态和事件为必需，画面、预览、结束来访、开门分别授权。
3. HA → 设置 → 设备与服务 → 添加集成 → FERMAX LYNX Gateway，输入网关地址和配对码。
4. HA 保存独立凭据，不保存管理员密码或配对码。可随时在网关撤销；重置网关密码也会使旧授权失效。

HTTP 仅用于可信局域网，HTTPS 证书需受信任。地址不允许携带密码、路径、查询参数；不跟随重定向。集成不会修改网关 HTTPS 设置或将其暴露到公网。

每个网关只配置一次。重复添加或配错网关时，新兑换的未使用授权应在对应网关中撤销。重新认证和“重新配置”都需要原网关的新配对码，可同时更新地址；完成后撤销旧授权。

## 提供的功能

- 网关设备：今日来电、今日开门确认、门禁网络、当前通话、只读自动开门策略。
- 各入口：门铃事件、活动事件；按授权显示访客图片、预览和结束来访按钮。
- 开门需要单独授予网关权限，还需在 HA 实体设置中手动启用“请求开门”，默认禁用。

协议确认不代表实体门已打开或锁好，因此不创建 lock 实体。控制绑定当前入口与通话，短时有效，不自动重试；超时可能表示结果未知，不要反复点击。

画面是当前通话或预览的 JPEG，不含双向语音。图片轮询不会主动发起预览，无新鲜画面时返回不可用。部分仪表盘可能仍保留上次显示的图，请同时查看实体状态。

## 自动化与断线

门铃实体将呼入映射为 HA 标准 `ring` 事件，活动实体保留 `incoming` 类型。推荐监听 `fermax_lynx_doorbell` 总线事件，用 `entity_id` 筛选对应入口的门铃实体，见[英文手册示例](../README.md#automations-and-reconnect-behavior)。该事件支持首次来电，不会因为 HA 启动恢复实体而误触发。自行监听实体状态时，应过滤恢复和 unknown/unavailable 状态变化。

断线时实体不可用，后台指数退避重连。历史记录仅用于推进游标，**重连或 HA 重启不会补播错过的门铃**。超过 30 秒的实时事件、重复事件 ID、同一通话的重复呼入会被忽略。HA 停机不会影响网关自己的响铃与自动开门策略。

若授权过期，按 HA 提示生成新配对码重新认证。若缺少画面或按钮，检查权限并用新配对码重新配置。诊断信息只包含版本、连通状态、权限名称和入口数量，不包含地址、凭据、住户名称、图片或通话 ID。

后续可申请 HACS 默认商店收录，目前支持的是“自定义仓库安装”，两者不同。版本采用 SemVer，与网关版本独立。
